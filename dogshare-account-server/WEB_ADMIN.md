# DogShare 配对管理后台

网页后台是配对账号服务的一部分，默认关闭。升级前的配对仍然不限时。新配对默认限时 24 小时，需要支持画面激活的 A 端；B 端沿用现有的授权检查。旧版独立账号服务不受影响。

- 配对列表显示 A、B 用户名、登录关联的设备、启用状态、在线状态和最后活动时间。设备信息用于路由和审计。
- 每组配对有一条最多 500 字的多行备注，可在列表中添加、编辑或清空。搜索支持备注内容；保存后持久化到数据库，并记录管理员及备注修改前后的内容。升级时现有配对的备注初始为空，原账号、会话和 24 小时计时保持不变。
- 每次可生成 1–25 组配对。新配对编号、A/B 用户名和随机密码都是 8 位字母数字。生成或重置的密码直接显示在配对列表，生成后也可下载 CSV。升级前的账号和密码继续有效；旧密码未留存，只有重置后才会在列表里显示新密码。
- 新配对初始为「待激活」。A 首次成功显示 B 的远控画面后上报，服务端从收到有效上报开始计时 24 小时。登录、领票、连接失败、重连和密码重置均不会启动或延长有效期。到期后两端不能登录或远控；已建立的远控在下次授权检查时断开。
- 管理员可为已过期的整组续期，恢复为「待激活」。下次成功显示远控画面才开始新的 24 小时，原账号密码和停用设置不变。
- 单端或整组可踢下线、停用或启用。踢下线撤销现有会话和远控授权，原密码可重新登录；停用会同时阻止登录，直到重新启用。重置某端密码也撤销该端已有会话。
- 配对账号每次成功登录只保留最新会话，换电脑无需先解绑。如果用户同机切换 A/B 时没有旧登录凭据，且无法用原客户端登出，可以单独踢掉该设备上原账号的一端，再让用户登录新账号。
- 登录、成功登出、掉线、会话过期、重新在线和换绑记录从后台启用后开始采集。管理员操作记录管理员、时间、配对和操作对象；不记录明文密码或会话凭据。
- 客户端认证复核通常每 30 秒一次。A 端登录后通过配对查询接口读取本组 B 的同一在线状态；该字段不影响设备 ID 的返回和原连接流程。连续 90 秒没有经过验证的活动，后台将对应账号标记为离线；这是超时判断，不是程序退出或网络故障的确切时间。已经建立的远控在下次授权复核时发现撤销，正常间隔是 30 秒。

## 部署前准备

先备份现有 SQLite 数据库，沿用配对服务的原数据卷和项目。生产上线应将管理路径限制在 VPN、运维网络或管理员的明确 IP 白名单内；不能把公开的设备登录接口和私有的管理路径一起限制或一起暴露。 如果同一域名还托管其他网站，建议给管理页使用独立的 HTTPS 子域名，避免共享浏览器来源。

管理员身份与设备账号分开。为每位操作人员创建独立管理员，密码通过交互式隐藏输入设置；设备用户的 `--admin` 显示标记不会赋予网页管理权限。

```sh
cd /opt/dogshare-paired-account
docker compose -p dogshare-paired-account exec accounts python -m dogshare_account_server.admin create-web-admin ops-frank
# 禁用某个管理员，立即撤销其网页会话：
docker compose -p dogshare-paired-account exec accounts python -m dogshare_account_server.admin disable-web-admin ops-frank
```

首次开启时，配对服务 `.env` 可使用下列设置。仅在反向代理已配置可信 HTTPS、并限制管理路径后开启：

```dotenv
DOGSHARE_ADMIN_ORIGIN=https://phenoseed.com
DOGSHARE_ADMIN_PATH=/dogshare-paired-account/admin
DOGSHARE_ADMIN_SESSION_TTL_SECONDS=3600
```

`DOGSHARE_ADMIN_ORIGIN` 只填浏览器实际访问的 HTTPS 来源，不带路径。`DOGSHARE_ADMIN_PATH` 是浏览器可见的管理路径，用于 Cookie 和重定向；反向代理仍将服务前缀剥离后，把管理请求转发至应用的 `/admin/`。管理页要求可信代理传递 HTTPS 协议，沿用现有服务的明确代理 IP 设置。限制管理路径及它的所有子路径（包括 `/api/` 和 `/assets/`）。

生成的配对密码在数据库中单独留存明文，仅登录后的配对列表可查看；登录仍使用密码哈希，管理员密码也只存哈希。数据库备份和 CSV 都应按凭据保管。CLI 手动设定密码会清除该账号在网页显示的旧值。

管理员会话使用 HTTPS 限定 Cookie；写操作校验来源和 CSRF 请求头。管理接口没有跨域开放，凭据响应禁止缓存。默认不开放 Web 入口；保持 `DOGSHARE_ADMIN_ORIGIN` 为空即可关闭管理路由。
