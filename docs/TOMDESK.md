# TomDesk：Windows 文字悬浮窗首版

启用账号门禁的新版本请先阅读 [账号交付说明](TOMDESK_ACCOUNTS.md)：A、B 两端均需更新并登录；本文关于原版 RustDesk 发送端的兼容说明仅适用于未启用账号门禁的字幕首版。

TomDesk 基于本仓库的 RustDesk，首版增加 Windows 桌面文字悬浮窗。它使用现有聊天连接传递文字，接收方主动开启后，将该会话收到的聊天消息显示在置顶窗口中，聊天记录仍然保留。

本次实现的是文字悬浮窗核心流程，并非荣耀小控全部功能的复刻。

## 使用方法

1. 在接收文字的一端运行 Windows 版 TomDesk，建立正常的远程连接。
2. 打开相应会话的聊天面板，开启文字悬浮窗。首次开启会显示预览，便于确认位置和样式。
3. 发送方在普通聊天输入框输入文字并发送；接收方的悬浮窗显示最新收到的消息。
4. 在 B 端聊天面板打开“字幕设置”，通过“字幕宽度”和“字幕高度”调整显示区域，另可调整字体、字号、文字颜色和不透明度。拖住可见文字笔画移动字幕；长文本可在点击文字激活后通过鼠标滚轮查看。浮窗本身继续保持纯文字，不显示缩放手柄。
5. 在接收方聊天面板关闭字幕开关，停止显示。再次收到聊天消息不会自行重新开启，需接收方再次主动打开；连接关闭时也会清理该来源的字幕。

发送方可以使用原版 RustDesk，因为传输内容仍是普通聊天消息。只有 Windows TomDesk 接收端提供这个桌面悬浮窗。发送方不能通过聊天消息开启接收方的窗口，也不能远程修改接收方的显示设置。

悬浮窗显示最新一条消息，不将多条历史消息拼成字幕；历史内容可以在普通聊天面板查看。同一 Flutter 窗口引擎一次显示一个选定会话的字幕。

## 显示和品牌范围

- 浮窗仅绘制字幕文字，支持中文、多行文字、自动换行和滚轮滚动；TomDesk 与来源保留为系统窗口信息，管理入口仍在正常聊天面板。
- 浮窗背景透明，不绘制标题、外框、按钮、操作条或滚动条，默认文字为 100% 不透明；需要清晰文字时保持 100%。不透明度范围为 0%–100%，每档 5%；0% 会使文字完全透明，可从聊天面板的“字幕设置”恢复，设置面板本身不受该值影响。
- 透明背景使用原生分层窗口的颜色键，字体采用灰度抗锯齿以避免 ClearType 彩色字缘；文字边缘在不同背景上仍可能出现细暗边，需实际目视验收。透明空白区域不会接收鼠标点击，拖动必须落在可见文字笔画上；长文本可点击文字激活后使用滚轮。宽高在“字幕设置”中调整：默认 640×360，宽度 240–2560、高度 80–1440，每档 20，均为随屏幕缩放换算的逻辑像素。宽度控制换行，高度控制可见行数；调节不会移动窗口，收到新消息也不会恢复默认大小。设置在当前 Flutter 窗口引擎生命周期内保持，重启后恢复默认；过大的尺寸可能超出屏幕，可在面板调回。
- Windows 捕获测试版在显示文字浮窗前请求排除该窗口的捕获。系统拒绝请求时保持浮窗隐藏，聊天仍可使用；录制效果需用实际采集模式验证。
- Windows 运行时应用名称和产品显示名称改为 TomDesk，原作者版权声明、LICENSE 和上游项目信息保留。
- 现阶段保留 `rustdesk.exe`、`librustdesk.dll`、Flutter 包名和内部桥接符号，兼容既有构建及打包脚本。应用图标和其他平台的品牌资源尚未替换；Windows 主要显示名称使用 TomDesk。
- Windows 的应用配置名称随运行时品牌改为 TomDesk；原 RustDesk 的本机配置不会自动迁移。现有签名定制配置仍由上游加载流程处理。

## 验收清单

- 默认关闭时，普通聊天行为保持不变，不出现悬浮窗。
- 接收方开启后，发送中文、英文和多行消息，普通聊天及悬浮窗都能显示；新消息替换悬浮窗中的旧消息。
- 字体、字号、颜色、不透明度调整立即可见；超出窗口的文字可以滚动查看。
- 移动、缩放、关闭窗口正常，关闭后新消息不会重新打开窗口。
- 同时连接两个会话时，未选中会话的消息不会串到当前字幕中。
- 断开或关闭字幕来源会话时，不留下旧字幕或继续接收该会话的内容。
- 原版 RustDesk 发送普通聊天消息，Windows TomDesk 接收并显示；未开启功能时走原有聊天流程。
- 125% / 150% 显示缩放、多显示器移动及会话窗口关闭后，没有残留窗口或崩溃。

完整应用的编译结果、双端联机和桌面显示效果，需要分别验证；单元测试不能代替这些人工验收项。


## 修改涉及的原有路径

- `flutter/lib/common/widgets/chat_page.dart`：添加 Windows 字幕开关和样式设置，原有聊天组件保留。
- `flutter/lib/models/chat_model.dart`：收到消息后按来源更新字幕，关闭或释放会话时清理窗口。
- `flutter/lib/models/server_model.dart` 与 `flutter/lib/models/model.dart`：连接断开、重连或关闭时停止字幕，避免留下旧内容。
- `flutter/windows/runner/flutter_window.cpp` 与 `CMakeLists.txt`：为主引擎和多窗口引擎注册新插件，并编译原生窗口代码。
- `src/common.rs`、Windows `main.cpp` / `Runner.rc` 与 `libs/portable/Cargo.toml`：设置 Windows 默认名称、产品信息和单文件包名称。
- `src/lang/*.rs`：按仓库约定追加新翻译键，填写简体中文；没有修改已有译文。

Windows 接收端的当前会话开启字幕后，收到该会话消息只更新字幕和聊天记录，不再自动展开聊天面板、恢复或置前聊天窗口，也不自动切换到该会话。用户仍可手动打开聊天面板查看记录；其他会话及未开启字幕的普通聊天保留上游提醒流程。开启字幕后，可以手动最小化聊天窗口继续接收字幕。

Windows 改名沿用上游定制客户端机制，因此本机配置、服务和 URI 名称随之变化，上游自动更新检查也按定制客户端处理。已有 RustDesk 配置不会自动迁移。

交付时可保留完整程序目录，并把目录中的启动程序副本命名为 `TomDesk.exe`，再使用上游 `libs/portable/generate.py` 生成单文件包。单文件包解压到独立的 TomDesk 目录；编译目录中的内部名称保持不变。
