# DogShare 配对版

B 手动登录成功后自动隐藏主窗口。「－」和「×」也隐藏主窗口，不创建 DogShare 托盘图标，不占任务栏。再次双击同一个 B 端 EXE 会恢复已有主窗口。主窗口的「退出程序」关闭接收端和当前远控，保留已保存的登录凭据；「退出登录」则撤销当前账号会话并回到登录页。登录失败、取消、启动时恢复已保存的登录或定期授权检查不会自动隐藏。连接成功后，B 的连接管理器直接以最小化状态出现在任务栏。连接管理器的「－」和「×」也最小化到任务栏，当前远控继续。点击任务栏可以恢复详情，红色「断开连接」仍用于结束远控。如果无法注册重复启动恢复，窗口会退回任务栏，方便恢复和退出。

| Windows x64 便携程序 | 登录账号 | 用途 |
| --- | --- | --- |
| `DogShare-Control.exe` | 本组 A 账号 | 连接本组 B，远程桌面、控制实时字幕 |
| `DogShare-Receiver.exe` | 本组 B 账号 | 接收本组 A 的远控、拖动字幕卡片、查看状态和断开连接 |

每组由管理员生成两个独立的账号和密码。每个配对账号只保留最新一次成功登录；换电脑直接登录即可。设备 ID 和 UUID 用于路由和审计。A 不需要知道或输入 B 的设备 ID；客户端会向账号服务查询配对设备。B 登录后即允许本组 A 发起远控，不需要单独的设备密码或每次点接受。B 可以在本机查看连接、断开、退出登录。

客户端内置 `phenoseed.com:21116`（ID 服务）、`phenoseed.com:21117`（中继）及对应服务器公钥。配对账号使用 `https://phenoseed.com/dogshare-paired-account`，与原账号版的账号库隔离。同一 Windows 用户可以先用「退出程序」完全关闭当前程序（托盘版从托盘退出），再打开另一端程序，顺序使用 A 和 B。要做双端远控，仍需在不同电脑上同时运行。

## 使用

A、B 登录前使用同样的简洁账号登录布局。登录后，首页显示当前账号；A 可连接配对设备，B 可查看自己的连接状态。在同一台电脑切换账号或 A/B 时，直接输入新账号密码即可，不需要旧登录凭据或管理员解绑。服务端先验证新账号的密码、角色和配对，再撤销同机旧登录；重装导致设备 ID 变化也适用。每个账号只保留最新一次成功登录，其他电脑上的旧登录及远控在下一次授权检查时失效，正常检查间隔为 30 秒。新登录失败不会挤掉原登录，换电脑或切换账号不会重置配对有效期。启用状态查询的配对服务会让 A 在配对卡片显示 B 的在线状态；蓝点代表 B 最近有有效账号心跳，连接按钮仍可使用。

A 的远控工具栏显示固定工具栏、适应窗口、操作模式、聊天与语音、录屏和红色 ×。「适应窗口」缩放远程画面以适应 A 的当前窗口。「控制」恢复键鼠操作，继续用当前的键盘设置；「浏览模式」只看画面。聊天按钮可进入文字聊天、发起或结束语音通话。新版 B 正常登录后无需设置或点接听，本组 A 在已授权的远控会话里点「语音通话」即可接通。B 在连接管理器只显示通话状态，无语音按钮或来电弹窗；A 可结束语音，B 可断开远控。升级时若 B 仍使用旧登录，需要退出并重新登录一次。点工具栏红色 × 可退出当前远控，也可以沿用远控窗口的关闭入口。

1. B 打开 `DogShare-Receiver.exe`，输入本组 B 的账号、密码，等待连接。
2. A 打开 `DogShare-Control.exe`，输入本组 A 的账号、密码，在「配对设备」下点「连接」。
3. 连上后，A 在远控工具栏打开「文字聊天」。拖动窗口右下角可以调大或缩小聊天窗口。输入框内部右侧的 × 只清空当前输入，不删除聊天记录。发送箭头一直显示在输入框外的右侧。关闭「显示弹幕」时按普通聊天发送；打开后，B 收起聊天侧栏，A 继续使用同一个输入框。
4. 「字幕设置」可以调整字号、字体、颜色、文字不透明度和「实时发送」。实时发送开启时，B 随输入更新（中文输入法确认后更新）；关闭时点「发送」才更新。每次更新替换卡片旧文字；发送后清空 A 的输入框不会清掉 B 最后发送的字幕。关闭「显示弹幕」会收起 B 的卡片。
5. 「字幕设置 → B 端显示区域」默认自动适应宽高。B 先换行和扩大显示区域，必要时适当缩小字号；关闭自动适应后，A 可手动调宽度和高度，B 会按所在屏幕的可用范围限制尺寸。调整立即应用到正在显示的文字。太长一屏放不下时，B 从第一页开始显示，A 可在聊天窗口用箭头翻页。超过约 2,000 个常见汉字的发送上限时，A 保留输入并提示分段发送。
6. B 平时只显示字幕，整张卡片（包括文字和左上角）的点击会交给下方窗口。想移动时，先按住 Alt，再用鼠标左键从卡片任意位置拖动。拖动过程中，文字和淡色轮廓一起跟随鼠标；松手后轮廓消失，字幕留在新位置并恢复点击穿透。会话断开后卡片隐藏，在同一运行期间再次显示会沿用位置。

弹幕通过当前配对远控连接传输，B 不接收对应的普通聊天消息，也不会弹出聊天窗口。A 可以在聊天中查看点「发送」提交的文字。手动宽高与远端翻页需要 A、B 两端都升级。沿用原账号和自建服务器，无需迁移数据。

被控账号不能在控制版发起连接；即使通过旧程序或手填设备 ID，也无法取得远控授权。不同组之间不能互连，双方不能互换方向。首版只支持普通远程桌面及聊天字幕，不提供独立文件传输、终端、摄像头、端口转发或 RDP。

便携模式下，B 需要先登录 Windows、登录配对账号并保持 DogShare 运行。开机后无人登录 Windows 的系统服务模式不在本版范围内。

## 服务器管理

```sh
cd /opt/dogshare-paired-account
tdpairs() { docker compose -p dogshare-paired-account exec accounts python -m dogshare_account_server.admin "$@"; }
tdpairs create-pairs --count 10 --output /data/pairs-batch-01.csv
tdpairs pairs
```

批量生成的文件含每组两套明文初始密码，保存在容器挂载的 `/data` 中，只供管理员分发。账号数据库保存密码哈希。把 A 密码发给控制方，B 密码发给接收方；不要互相共享。

- `tdpairs logout-pair 配对编号` 撤销本组两端当前登录和连接授权，之后可重新登录。
- `tdpairs disable-pair 配对编号` 撤销授权并停止本组登录。活动连接在下一次服务端授权复核后断开。
- 换电脑时，同一个配对账号在新电脑登录成功后，旧登录及相关连接授权即失效，无需管理员解绑。已建立的远控会在下次授权复核时断开，正常间隔为 30 秒。

## 验收

在两台 Windows 电脑上确认正确配对可以连接，跨组和角色反向连接被拒绝；B 不点接受，仍显示当前连接和断开按钮；账号下线会使当前会话断开。字幕验收：从 A 检查中文输入法、手动和实时发送、字号字体、颜色透明度、清空与关闭；先在 B 打开聊天，再让 A 开启「显示弹幕」，确认 B 收起聊天；在 B 先按住 Alt，再从卡片任意位置用左键拖动，确认松手前文字和轮廓同步跟随，松手后轮廓消失；不按 Alt 时点击左上角、字幕文字及空白处，确认都能点到下方窗口。断开后卡片消失。普通聊天仍走原通道。
